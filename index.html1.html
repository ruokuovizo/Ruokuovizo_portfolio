03 — Selected Project

Featured work.

MACHINE LEARNING • COMPUTER VISION

Naga Shawl Identification

An image-based machine-learning project for identifying traditional Naga shawl patterns using feature extraction and classifier evaluation.

Project Overview

The project explores image-based identification of Naga shawls. EfficientNetV2 is used for feature extraction, followed by evaluation of different machine-learning classifiers.

Development Process

01

Image Input

Shawl images are provided as input to the identification system.

02

Feature Extraction

EfficientNetV2 extracts meaningful features from the shawl images.

03

Classifier Testing

Different classifiers are tested using the extracted features.

04

Evaluation

Classifier performance is compared using accuracy.

Model Flow

The overall process uses EfficientNetV2 for feature extraction before passing the extracted features to a classifier.
